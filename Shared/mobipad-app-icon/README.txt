MobiPad app icon - layer files (1024 x 1024, transparent unless noted)

light/   Default appearance. background.svg is a reference for the gradient
         (#A3304F -> #560F26); set it as the icon's background fill instead.
         Use accent-gold.svg (or accent-teal.svg).
dark/    Dark appearance (pick: bordeaux phone). Background #2A0B16 -> #0E0307.
         Layer order back to front: phone, controls, accent-glow, accent.
clear/   Clear / tinted appearance (pick: cut-out controls).
         phone-cutout.svg already has the controls punched out; put accent.svg in front.
alternatives/  The other dark and clear ideas, same layer naming.
previews/      Flattened images for checking only. Don't import these.

No masks or filters are used, so Icon Composer can apply its own glass, shadow and depth.
